# IntoTheDeep
Code can be found in Team772/src/main/java/org/firstinspires/ftc/team772

Github repository for FTC 772's Into the Deep 2024-25 Season.\
Code for the first iteration of the robot is on the main branch. Code for the second iteration is on the v2 branch.

Using
---
1. Through Github, create a new repository with the ParallelPlate template, or, to start from scratch, clone the [FTC SDK](https://github.com/FIRST-Tech-Challenge/FtcRobotController). 
2. Download and set up 
    - [Android Studio](https://developer.android.com/studio)
    - [IntelliJ IDEA Community](https://www.jetbrains.com/idea/download/) or Ultimate (free for students if you apply [Github](https://github.com/edu/students) or [Jetbrains](https://www.jetbrains.com/community/education/#students))
      - Install the [Android Plugin](https://plugins.jetbrains.com/plugin/22989-android)
  
    either through the provided links or via the [Jetbrains Toolbox](https://www.jetbrains.com/toolbox-app/).

3. Install [git](https://www.git-scm.com/)
4. [Clone the repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository)
